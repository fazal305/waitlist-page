# Contributing

Thanks for taking a look. This is a small portfolio project, so contributions are welcome but kept focused.

1. Open an issue first for anything beyond a typo or small bug fix.
2. Fork, create a branch, and run `npm install && npm run dev`. The dev server mocks the API when no Supabase env vars are set.
3. Before opening a PR, run `npm run build && npm run size` and make sure the bundle stays under 50 KB gzipped.
4. Keep styling in vanilla CSS with the existing custom properties, and don't add UI frameworks.
5. Check the page at 375 px wide, with keyboard only, and in dark mode.

By contributing, you agree your work is released under the MIT License.
