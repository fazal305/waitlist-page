# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful and constructive, assume good intent, and keep discussion about the work. Harassment, personal attacks and discriminatory language aren't accepted in issues, pull requests or any other project space.

Report unacceptable behavior to **fazalabbas2002@gmail.com**. Reports are handled confidentially.
