# Security Policy

If you find a security issue in this project, please report it privately by email to **fazalabbas2002@gmail.com** rather than opening a public issue.

Include what you found, steps to reproduce, and the impact you expect. You'll get a reply within a few days, and a fix will be prioritized for anything that exposes stored email addresses or allows bypassing the rate limit.

Only the `main` branch and the live deployment are supported.
